# 42 Common Core

Selección de proyectos desarrollados durante mi formación en **42 Málaga**.

Programación en C · Algoritmos · Unix · Procesos · Redes · Gráficos

## Proyectos

| Proyecto | Área | Descripción |
|---|---|---|
| [Libft](https://github.com/Martin-dev86/Libft) | Fundamentos de C | Biblioteca propia de funciones esenciales y utilidades reutilizables. |
| [ft_printf](https://github.com/Martin-dev86/Ft_Printf) | Formato y variádicas | Recreación de `printf` para trabajar conversión, formato y argumentos variádicos. |
| [get_next_line](https://github.com/Martin-dev86/Get_next_line) | Entrada/salida | Lectura incremental de archivos y gestión precisa de memoria y buffers. |
| [push_swap](https://github.com/Martin-dev86/Push_swap) | Algoritmos | Ordenación eficiente con un conjunto limitado de operaciones sobre pilas. |
| [pipex](https://github.com/Martin-dev86/Pipex) | Unix y procesos | Reproducción de pipelines mediante procesos, pipes, redirecciones y ejecución de comandos. |
| [minishell](https://github.com/Martin-dev86/Mini-Shell) | Sistemas | Shell colaborativa con parsing, procesos, señales, redirecciones y variables de entorno. |
| [cub3D](https://github.com/Martin-dev86/Cube-3D) | Gráficos | Motor gráfico inspirado en raycasting para construir una experiencia 3D desde C. |

## Competencias desarrolladas

- Diseño modular, depuración y gestión manual de memoria en C.
- Algoritmos, estructuras de datos y análisis de eficiencia.
- Procesos, descriptores de archivo, señales y comunicación mediante pipes.
- Trabajo colaborativo, control de versiones y resolución autónoma de problemas.
